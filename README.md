# hemsida

Hemsidan för Proximus Sverige AB.

- `main` publiceras direkt på proximus.se. Rör inte `CNAME`.
- `utkast` är arbetsgrenen. Slå ihop med `main` först efter godkännande.
- Statisk sida. Typsnitt och GSAP ligger lokalt i `assets/`. Foton länkas tills vidare från Unsplash och bör läggas lokalt före publicering.
